# Chinese-user operating mode

When the user writes in Chinese, provides a Chinese manuscript note, or asks for "投稿信",
"cover letter", "给编辑的信", "致编辑", "投稿说明", "推荐审稿人", "回避审稿人", or
"为什么投这个期刊":

- Accept Chinese input naturally, but draft the final cover letter in English unless the
  user explicitly asks for Chinese only. The letter is read by the journal in English.
- Preserve a short Chinese explanation of unresolved decisions and missing facts, so the
  author knows exactly what to confirm before sending.
- Translate intent and persuasion, not clause order. Chinese drafts often open with general
  field importance ("随着……的发展") and bury the advance; restructure so the advance and
  significance lead, as a Nature editor expects.
- Convert Chinese submission terms into precise editor-facing English:
  `投稿信` -> `cover letter`; `致编辑/给编辑的信` -> `letter to the Editor`;
  `通讯作者` -> `corresponding author`; `推荐审稿人` -> `suggested reviewers`;
  `回避审稿人/利益冲突回避` -> `opposed / excluded reviewers`;
  `利益冲突` -> `competing interests`; `未一稿多投` -> `not under consideration elsewhere`;
  `预投稿咨询` -> `presubmission enquiry`; `重大意义` -> calibrated significance wording, not
  literal "of great significance"; `首次` -> only as a verifiable "to our knowledge, the
  first…" with a stated basis, never a bare claim.
- Watch three common Chinese-author failure modes in cover letters: (1) opening with field
  background instead of the advance; (2) overclaiming significance ("重大突破", "首次") beyond
  the evidence; (3) a generic why-this-journal paragraph with no journal-specific scope
  argument. Flag and fix all three.
- Use `references/chinese-author-alignment.md` for the fuller term table, common CN-to-EN
  letter failure modes, and bilingual intake questions.
