# Source Basis

Use this file when a user asks why a rule exists, wants primary-source
justification, or needs to audit the `nature-submission-package` skill against
real submission guidance.

## Source map

| Skill rule | Primary support |
|---|---|
| A completed submission package includes manuscript, figures, cover letter, data-availability statement, competing interests declaration, and author contributions. | Nature Portfolio "For Authors" pages list these as required for all submissions. |
| A Reporting Summary is required for most flagship and sub-journal research papers. | Nature Portfolio Reporting Summary policy; Life Sciences Reporting Summary checklist. |
| Extended Data figures and tables are required for Nature flagship submissions. | Nature "Guide to Authors" — Extended Data section. |
| Every figure referenced in text must have a corresponding file and vice versa. | Nature "Guide to Authors" — figure preparation; standard editorial practice. |
| The cover letter should name the target journal and the journal name must be consistent across all artefacts. | Standard editorial practice; inconsistent journal names cause processing errors. |
| CONSORT/STROBE/ARRIVE/MIQE/PRISMA checklists are required when the study type matches. | EQUATOR Network; each standard's official statement. |
| Code and model availability are mandatory for Nature Machine Intelligence and Nature Computational Science. | Nature MI and Nature Comp Sci "Guide to Authors". |
| Presubmission enquiries are recommended for Nature flagship. | Nature "Guide to Authors" — presubmission enquiries. |
| Journal requirements change; always verify against the current submission page. | No single source — this is a pragmatic safeguard against catalogue drift. |

## Catalogue versioning

The `references/journal-catalog.md` file carries a version date (currently
2026-06). When a user reports that a journal's requirements have changed,
update the catalogue entry and the version date. The skill prints the version
date in every output so the author knows how fresh the information is.
