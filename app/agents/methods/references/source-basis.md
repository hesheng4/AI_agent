# Source Basis

Use this file when a user asks why a rule exists, wants primary-source justification, or needs
to audit the `nature-methods` skill against real reporting and ethics guidance.

## Source map

| Skill rule | Primary support |
|---|---|
| Methods must let an independent group reproduce the work. | Nature Portfolio reporting standards require Methods to provide enough detail to allow the work to be reproduced, including materials, procedures, and analysis. |
| Antibodies, cell lines, and organisms must be identified with source and validation. | Nature Portfolio reporting standards and the Reporting Summary require antibody validation and identifiers, cell-line source/authentication/mycoplasma status, and organism strain/sex/age details. |
| Cell lines should be authenticated and tested for mycoplasma. | Nature Portfolio policy and the Reporting Summary ask for cell-line authentication (e.g. STR) and mycoplasma contamination testing. |
| Research resources should carry persistent identifiers (RRIDs). | The Research Resource Identifier (RRID) initiative provides persistent identifiers for antibodies, cell lines, organisms, and tools to make them unambiguous and findable. |
| Rigor elements (randomisation, blinding, inclusion/exclusion, sample-size rationale) must be reported. | The Nature Portfolio Reporting Summary requires statements on randomisation, blinding, data-exclusion criteria, and how sample size was determined. |
| Software and code used for analysis must be named with versions. | Nature Portfolio reporting standards and code-availability policy require analysis software and custom code to be identified, with versions and availability. |
| Human research needs ethics approval, Helsinki conformance, and informed consent. | Nature Portfolio ethics policies require IRB/ethics approval, conduct in accordance with the Declaration of Helsinki, and informed consent for human-participant research. |
| Animal research needs ethics approval and should follow ARRIVE reporting. | Nature Portfolio policy requires animal-ethics approval and recommends ARRIVE 2.0 reporting for in vivo experiments. |
| Clinical trials must be registered and reported per CONSORT. | Nature Portfolio policy requires trial registration; CONSORT is the standard for reporting randomised trials. |
| Discipline reporting standards (STROBE, MIQE, PRISMA, etc.) apply by study type. | The EQUATOR Network maintains the major reporting guidelines used to assess methods completeness across study designs. |
| Vague phrasing undermines reproducibility. | Reproducibility-focused editorial guidance (Nature's reproducibility initiatives) identifies underspecified methods as a key driver of irreproducibility. |
